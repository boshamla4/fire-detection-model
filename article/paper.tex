\begin{abstract}
Forest fires represent one of the most destructive natural disasters,
causing irreversible ecological and economic damage worldwide. Early and
accurate detection is critical to minimizing their impact, yet most
existing AI-based approaches rely on centralized cloud processing,
introducing unacceptable latency in remote, low-connectivity areas.
This paper proposes an edge-cloud distributed architecture for
real-time forest fire and smoke detection deployable on Unmanned Aerial
Vehicles (UAVs). The detection backbone is based on YOLOv11, the latest
generation of real-time object detection networks, fine-tuned on the
21,527-image D-Fire public dataset. The proposed system partitions
computation between an onboard edge inference unit and a cloud
aggregation layer, achieving end-to-end detection latency below
5 seconds even under constrained network conditions. A real-time
operational dashboard provides geospatial visualization of active fire
events and alerts for emergency responders. Experimental results
demonstrate a mAP@0.5 of \textbf{[TBD]}, edge inference latency of
\textbf{[TBD]\,ms} on CPU, and an end-to-end latency of
\textbf{[TBD]\,s}, validating the proposed architecture for operational
wildfire monitoring.
\end{abstract}

\section{Introduction}

Forest fires are a growing global threat, accelerated by climate change
and prolonged droughts. In 2023 alone, wildfires burned over
13.4 million hectares across Europe, North Africa, and North
America~\cite{liu2025advancements}. The critical detection window is
narrow: early identification within the first minutes after ignition
drastically reduces the burned area and intervention cost.

Satellite-based systems such as NASA MODIS and VIIRS introduce delays
of 30 minutes to several hours due to orbital revisit
periods~\cite{morchid2025fire}. Ground sensor networks offer
continuous monitoring but require costly deployment and have limited
spatial coverage. UAVs represent a compelling alternative—rapidly
deployable and capable of providing continuous low-altitude imagery.
When equipped with onboard AI inference, UAVs can detect fire and smoke
without relying on a persistent high-bandwidth cloud uplink.

Deploying high-performance deep learning models on edge hardware
introduces challenges: limited compute, restricted memory, and power
constraints. Furthermore, in wildfire-prone forested regions, network
connectivity is often absent (\textit{zone blanche}), making
cloud-dependent architectures unreliable precisely when needed most.

This work addresses these challenges with four contributions:
\begin{enumerate}
  \item An \textbf{edge-cloud distributed architecture} with graceful
        degradation under network loss, including LoRa fallback and a
        local event buffer.
  \item An \textbf{optimized YOLOv11 deployment} fine-tuned on the
        D-Fire dataset, with CPU-benchmarked ONNX export targeting
        embedded edge devices.
  \item A \textbf{real-time operational dashboard} consuming Supabase
        Realtime events for geospatial fire visualization and alerting.
  \item A \textbf{systematic latency analysis} across deployment
        configurations demonstrating sub-5-second end-to-end detection.
\end{enumerate}

The paper is organized as follows: Section~\ref{sec:related} surveys
related work; Section~\ref{sec:architecture} presents the proposed
system; Section~\ref{sec:methodology} describes the dataset and model;
Section~\ref{sec:results} reports experiments; Section~\ref{sec:dashboard}
describes the dashboard; Section~\ref{sec:conclusion} concludes.

\section{Related Work}
\label{sec:related}

\subsection{Statistical and Physics-Based Approaches}
Early fire risk systems relied on logistic regression, Bayesian networks,
and CFD models, achieving AUC values up to 0.986 in controlled
conditions~\cite{liu2025advancements}. These approaches cannot perform
real-time visual localization of active fire events.

\subsection{Machine Learning for Fire Prediction}
Khanmohammadi \textit{et al.}~\cite{khanmohammadi2024automl} combined
AutoML with GANs to address class imbalance in a Canadian wildfire
dataset, achieving 91\% binary accuracy. Liu \textit{et
al.}~\cite{liu2025advancements} confirm that ensemble methods
(Random Forest, XGBoost) deliver AUC above 0.9 on benchmark datasets
while remaining interpretable. These approaches operate on aggregated
tabular features and cannot localize fire spatially.

\subsection{Deep Learning for Visual Detection}
Sathishkumar \textit{et al.}~\cite{sathishkumar2023forest} demonstrate
that transfer learning with Learning Without Forgetting (LwF) mitigates
catastrophic forgetting when adapting CNNs to new fire datasets, with
Xception + LwF reaching 91.41\% accuracy on BowFire. Priya \textit{et
al.}~\cite{priya2025generative} combine GAN-generated synthetic data
with IoT-sensor CNN inference, reporting up to 85\% false-positive
reduction. Neither work addresses edge deployment or latency.

\subsection{Real-Time Object Detection}
He \textit{et al.}~\cite{he2025yolov11} apply YOLOv11x to two public
fire datasets (WD and FFS), achieving mAP@0.5 of 0.901 with smoke
detection reaching 0.962. YOLOv11 reduces parameters by 22\% over
YOLOv8m while matching accuracy. Their evaluation is conducted
exclusively on cloud GPU hardware with no analysis of edge deployment
or end-to-end latency.

\subsection{IoT and AI Integration}
Morchid \textit{et al.}~\cite{morchid2025fire} review AI-IoT systems
for fire monitoring, identifying CNN-IoT hybrids achieving $>$90\%
early detection rates and 85\% false-positive reduction, while
highlighting real-time computational cost and remote connectivity as
critical open challenges.

\subsection{Research Gap}
No prior work simultaneously addresses (i) deployment on drone-mounted
edge hardware, (ii) graceful operation under intermittent connectivity,
and (iii) end-to-end latency quantification for operational fire
response. This paper fills this gap.

\subsection{UAV Edge Layer}

The edge unit runs \textbf{YOLOv11n} (nano variant), exported to ONNX
FP32 format via ONNX Runtime and benchmarked on CPU as a proxy for
embedded devices such as the NVIDIA Jetson Nano or Raspberry Pi 5 with NPU. Only structured detection events — bounding
box coordinates, class label, confidence score, GPS timestamp — are
transmitted. This reduces uplink bandwidth requirements by orders of
magnitude compared to raw video streaming.

Three operation modes govern transmission:
\begin{itemize}
  \item \textbf{Connected mode:} Events streamed in real time over
        4G/LTE or WiFi.
  \item \textbf{Disconnected mode:} Events written to a local JSONL
        buffer with timestamps. Flushed to cloud on reconnection.
  \item \textbf{Critical alert mode:} A minimal payload (GPS +
        confidence) is transmitted via LoRa 868\,MHz to the nearest
        relay node.
\end{itemize}

\subsection{Cloud Aggregation Layer}

The cloud backend aggregates events via Supabase Realtime
(PostgreSQL + WebSocket push). A spatial fusion module maintains a
live fire probability map. The alerting module triggers notifications
when confidence exceeds a configurable threshold over consecutive
frames.

\subsection{Dataset}

We use the \textbf{D-Fire} dataset~\cite{dfire2022}, containing 21,527
images annotated in YOLO format with two classes: \texttt{fire} and
\texttt{smoke}. Images are split 70/20/10 (train/val/test). Table~\ref{tab:dataset}
summarizes the class distribution.

\textbf{Preprocessing:} Images are resized to 640$\times$640. Mosaic
augmentation, random affine transforms, and HSV jitter are applied
during training. Histogram equalization is applied to hazy or backlit
images common in wildfire conditions.

Fig.~\ref{fig:pipeline}. YOLOv11 (released September 2024) improves
over YOLOv8 via C3k2 backbone modules for multi-scale feature
extraction and C2PSA attention in the neck, achieving a 22\% parameter

We evaluate two model variants:
\begin{itemize}
  \item \textbf{YOLOv11x} — maximum accuracy cloud GPU baseline.
  \item \textbf{YOLOv11n} — minimum parameters, edge deployment target,
        exported to ONNX and benchmarked on CPU as a proxy for embedded
        inference hardware.
\end{itemize}

\textit{Note:} Edge latency measurements are obtained via ONNX Runtime
on CPU, simulating embedded hardware. Real-world deployment on a Jetson
Nano with TensorRT INT8 would yield lower latency.

locally with no latency penalty, buffered to a JSONL file.

\section{Dashboard Implementation}
\label{sec:dashboard}

The real-time dashboard (Fig.~\ref{fig:dashboard}) is implemented as a
Next.js 14 web application with Tailwind CSS, backed by Supabase
Realtime. It is deployed on Vercel and requires no polling: detection
events are pushed via WebSocket within $\approx$50\,ms of the Supabase
insert.

Core features:
\begin{itemize}
  \item \textbf{Live fire map:} Leaflet.js with confidence-scaled
        heatmap circles for each detection event. Recent detections
        render at full opacity; events decay over time.
  \item \textbf{Fleet status panel:} Per-UAV GPS position, battery
        level, and connectivity state (Connected / LoRa / Disconnected).
  \item \textbf{Alert log:} Chronological event list with class,
        confidence, coordinates, and time-to-alert.
  \item \textbf{Statistics panel:} Confidence distribution histogram
        updated in real time.
\end{itemize}

\section{Conclusion}
\label{sec:conclusion}

This paper presented an edge-cloud architecture for real-time forest
fire and smoke detection using UAVs. By deploying a quantized YOLOv11n
model on the UAV and transmitting only lightweight JSON events, the
